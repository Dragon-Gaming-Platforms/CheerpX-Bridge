🐉 Dragon86 Hoster — embed test

This page plays the Dragon86 OS: it embeds index.html in a hidden 1×1 iframe and speaks bridge protocol v1 over real postMessage — hello every 400ms, 6s timeout note, data both ways, resize, exit. It also plays the OS side of the fs1 shared-folder protocol (v2): its hello advertises caps:["fs1"] and an in-memory fake filesystem answers the hoster's fs requests, mirroring src/bridge/hoster.ts and src/bridge/fs-bridge.ts in the OS repo. The parent page (this one) is NOT cross-origin isolated; only the iframe is.
